# ONG Mãos que Cuidam - Projeto Extensionista Cruzeiro do Sul

Projeto web estático desenvolvido para a disciplina de Extensão.

**Repositório:** https://github.com/francieliAlves674-blip/ong-maos-que-cuidam
**Deploy produção (Vercel):** https://ong-maos-que-cuidam.vercel.app
**Aluna:** Francieli Alves

## Tecnologias
- HTML5 semântico com ARIA
- CSS3 responsivo
- JavaScript modular (SPA, Storage, FormVoluntario)
- Vite

## Estrutura
- index.html / cadastro.html / projetos.html
- style.css
- js/bundle.js, js/FormVoluntario.js, js/main.js, js/menu.js, js/spa.js, js/storage.js

## Como rodar local
npm install
npm run dev

## CI/CD
Branch main com deploy automático na Vercel a cada push.
